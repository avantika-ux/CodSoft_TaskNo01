# Internship Tasks

Each folder includes its own README with the objective, approach, and files for that task.

## Tasks

| 1 | Data Cleaning & Preprocessing | [`Task1_Data_Cleaning`](./Task1_Data_Cleaning) | Cleaned a raw e-commerce dataset using Python/Pandas — handled missing values, duplicates, inconsistent formatting, and invalid entries, then exported an analysis-ready CSV. |

| 3 | Data Visualization Dashboard | [`Task3_Dashboard`](./Task3_Dashboard) | Built 6 static charts (bar, line, pie, histogram, scatter) with Matplotlib/Seaborn, plus a bonus interactive Plotly dashboard combining key visuals into a single browsable HTML page. |
